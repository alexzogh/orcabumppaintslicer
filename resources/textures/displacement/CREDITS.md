# Displacement texture credits

Textures Orca ships for the texture displacement gizmo. The gizmo scans this directory, so any
image dropped in appears in the picker; non-image files like this one are ignored.

## stlTexturizer

62 of the textures here come from [stlTexturizer](https://github.com/CNCKitchen/stlTexturizer) by
CNCKitchen (Stefan Hermann), which is licensed under the GNU Affero General Public License v3 — the
same license OrcaSlicer uses. They keep their original image data and were renamed to the naming
this directory already used.

## Not included

stlTexturizer also ships 29 textures whose file names (`hero-*`) indicate they derive from
[Hero Patterns](https://heropatterns.com/). Those are deliberately **not** bundled here: the
upstream project carries no attribution or license file for them, and the terms Hero Patterns
itself publishes could not be confirmed. They should not be redistributed until someone establishes
what license actually covers them, and adds the attribution that license requires.
